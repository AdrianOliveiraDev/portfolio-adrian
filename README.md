# 💻 Meu Portfólio Pessoal

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar os meus projetos de desenvolvimento de software, competências técnicas e a minha evolução académica/profissional na área de Tecnologia da Informação.

---

## 🚀 Sobre o Projeto

O portfólio é uma aplicação web simples, moderna e responsiva, projetada para destacar:
- **Projetos Principais:** Aplicações Desktop (Windows Forms / C#), Bancos de Dados (MySQL) e Algoritmos/Estruturas de Dados.
- **Sobre Mim:** Trajetória académica e interesses em Engenharia de Software e Desenvolvimento.
- **Competências Técnicas:** Tecnologias e linguagens que utilizo no dia a dia.
- **Contacto:** Links diretos para LinkedIn, GitHub e e-mail.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de conteúdo.
- **CSS3:** Estilização moderna, layouts responsivos e design flexível (`estilo.css`).
- **Assets/Design:** Favicon personalizado e imagens otimizadas para navegação.
